SpendSmart — College Expense Tracker

A clean and responsive expense tracking web application designed for college students to manage income, expenses, budgets, and analytics in one place.

This project helps students track daily spending, analyze categories, and stay within budget using an intuitive dashboard.

Features
Dashboard
Current balance overview
Total income and expenses
Monthly spending summary
Recent transactions list
Category spending pie chart
Transactions
Add income and expenses
Filter by category
Search transactions
Sort by date or amount
Delete transactions
Export transactions to CSV
Analytics
Category breakdown pie chart
Monthly spending trend chart
Category-wise summary cards
Budget Tracker
Set spending limits per category
Visual progress bars
Budget warnings when exceeded
UI Features
Dark mode toggle
Responsive layout
Sidebar navigation
Modal-based transaction entry
Category icons
Clean dashboard cards
Tech Stack
HTML5
CSS3 (Custom variables + responsive layout)
Vanilla JavaScript
Chart.js (for analytics graphs)
LocalStorage (data persistence)

How to Run
Download project files
Keep all files in same folder
Open index.html in browser

No installation required.

How to Use
Add Transaction

Click + Add transaction
Fill:

Description
Amount
Date
Category
Type (Income/Expense)

Click Add transaction

View Analytics

Click Analytics in sidebar to see:

Spending pie chart
Monthly trends
Category breakdown
Set Budget

Go to Budget tab

Enter amount → click Set

You will see:

Green → Safe
Yellow → Near limit
Red → Over budget
Export Data

Go to Transactions page
Click Export CSV

File downloads automatically.

Data Storage

This project uses browser LocalStorage.

Data includes:

Transactions
Budgets
Theme preference

No backend required.
